flb — work-log summaries from the command line

Fast-logbook-cli reads the same plain-text log format used by Fast-logbook-PWA, adds up work time per category over any date range, and prints the result in the format your next tool actually wants.

Pairs with → Fast-logbook-PWA

See usage Read the docs

Why flb

Small, direct, and easy to slot into a pipeline.

Six output formats

JSON, Markdown, TSV, CSV, JSONL, XML — pick what the next step in your pipeline expects.

Date-range aware

--from / --to narrow the summary to any window; omit both to cover the whole file.

Configurable rounding

--round rounds category hours to any minute increment you choose.

Ships as one binary

deno task build compiles flb — no runtime install needed to use it.

Usage

One positional file path, three optional flags.

flb [-f|--from <YYYY-MM-DD>] [-t|--to <YYYY-MM-DD>] \
    [-F|--format <json|markdown|tsv|csv|jsonl|xml|md>] \
    /path/to/file

# Whole file, default JSON output
flb ./work.log

# Restrict to January 2024, Markdown table
flb -f 2024-01-01 -t 2024-01-31 -F markdown ./work.log

# CSV, rounded to 15-minute increments
flb -f 2024-01-01 -t 2024-01-01 -F csv --round 15 ./work.log
OptionAliasDescriptionDefault
--from-fStart date, inclusiveentire file
--to-tEnd date, inclusiveentire file
--format-FOutput formatjson
--roundRounding unit in minutes1

Output formats

Same aggregated data, six shapes.

json markdown / md tsv csv jsonl xml

Install

Requires Deno 2.x to build.

# build the flb binary
deno task build

# or run directly without compiling
deno task start -- [options] /path/to/file
